# Super iOS UI Design

将 online-excel（麦当劳大本营）形成的页面语言用于移动网页：内容完整、结构紧凑、文字清楚、扁平化为主。视觉参考来自用户提供的 App Store、健康和音乐应用截图；这些是个人设计偏好，不是某个 iOS 版本的官方规范。

## 先确定页面角色

- 保留现有业务、数据、导航和文案，除非用户要求调整。先检查组件、样式加载顺序和最终生效的响应式覆盖。
- 主页面使用紧凑标题栏，内容页使用分组列表或完整卡片；精选入口可以使用一张有表现力的大卡片。
- 让同一条信息完整呈现。昵称、统计、标签和评论入口应属于同一行；不要把每个数字切成独立小圆块或统计卡片。
- 新增页面和控件沿用同一套字号、间距、圆角和状态，不为单个功能另造视觉风格。
- 具体起始值及页面对应关系见 [references/page-system.md](references/page-system.md)。数值可随内容和屏幕调整，用户最新反馈优先。

## 页面设计原则

### 紧凑顶部，内容优先

- 主标题栏以 48px 为起点，标题 19px，窄屏 18px；详情页标题 17px。减少顶部留白，不把 App Store 的大标题直接套到每个页面。
- 顶部统计使用单行文字，例如“今日新增 2”，灰色标签搭配稍深数字。不要做圆形徽章或上下叠放的小按钮。
- 不仿造网页外的系统状态栏或微信导航栏。正文从真实浏览器内容区开始，并统一各页面横向对齐。
- 内容保持单列，在大屏居中，参考最大宽度 720px；常规左右留白 20px，窄屏 16px。

### 连续内容与分组

- 首页成员列表直接放在白色内容面上，使用细分隔线；排行可以把整组行放在一个白色圆角容器里。
- 群史、更新记录及详情页采用浅灰底与白色分组面，卡片承载一段完整内容；不要嵌套多层卡片。
- 主要依靠间距、字号、字重和分隔线建立层级。普通列表、卡片、标签和筛选按钮不加装饰性阴影。
- 圆角服务于组件角色：搜索框约 12px，头像约 13–20px，内容组约 24px，精选卡片及底部面板约 28px。不要所有元素都变成胶囊。

### 文字和颜色

- 使用系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Helvetica Neue", "PingFang SC", sans-serif`。
- 正文和姓名通常 15–17px，分组标题 22–23px，辅助信息通常 12–13px。大字号主要留给精选内容和独立动画场景。
- 正文用 `#1c1c1e`，辅助文字用 `#8e8e93`，基础背景用白色或 `#f2f2f7`，交互强调用 `#007aff`。
- 彩色标签、危险操作或精选卡片可以有语义明确的颜色；不要给每个统计数字分配一套装饰色。
- 长正文自然换行；单行昵称可省略，但详情应能读到完整内容。不要靠无限缩小字号解决拥挤，优先调整布局。

### 按钮和导航

- 次要入口采用文字与箭头，例如“6 条评论 ›”；保持足够的点击区域，不做数字在上、文字在下的圆形按钮。
- 主操作用清晰的实色按钮；月份等轻量筛选用平面选中态，去掉莫名阴影、光晕和滤镜。
- 底部导航使用高透明浮动玻璃胶囊，选中图标和文字变蓝，单个浅灰胶囊滑动指示位置。玻璃材质集中用于浮动导航和操作层。
- Tabbar 详细参数优先读取同插件的 `$super-ios-glass-tabbar`。若该 skill 不可用，使用参考文件中的关键参数；本 skill 的页面规则不依赖外部工具。
- 尊重安全区，为页面末尾留足空间，保证最后一条内容和按钮能滚动到导航上方。

### 精选卡片、头像与动画

- 保留首页“玩头像”的完整蓝色精选卡片：真实头像拼贴、简短引导、明显标题、成员数量和“打开”入口。它是局部表现区，不扩散为全站装饰。
- 列表头像使用清晰的圆角方形；碰撞玩法可用圆形。头像来自真实用户数据，不写死人数，不遗漏新增成员或替换用户要求保留的历史头像。
- M 字母和圆圈动画首先保证头像可辨认。根据屏幕和人数调整头像尺寸、间距、轨迹或圈层，避免为了容纳人数把头像缩成小点。
- 动画时长、随机模式和保留头像等属于具体产品行为，按任务与现有实现维护，不将某一次动画配置变成所有项目的强制规则。
- 物理头像保持堆积、碰撞、弹跳、拖动和松手甩出的反馈。设备方向或重力功能按实际数据启用；需要授权时从明确的用户操作请求，拒绝或无数据时保留手指互动。
- 重力状态只在得到有效数据后展示“倾斜手机”等提示。页面尺寸改变时更新物理边界，关闭场景时清理动画、监听和物理实例。

## 已明确排除的做法

- 过高的 header、过大的常驻标题、占满首屏的无用顶部留白。
- 独立圆形评论计数、圆形“今日新增”数字块、零碎分割的统计 UI。
- 厚重不透明的 Tabbar、选中态越过相邻 tab、切换图标字形产生黑块或不一致的重量。
- 普通筛选控件和内容卡片的浮雕、强阴影、发光及多重玻璃效果。
- 为模仿系统界面添加无业务意义的系统控件、虚构内容或假设备能力。

## 实现与验证

- 优先收敛到可复用的样式或组件；修改现有多层 CSS 时找出最终有效覆盖，避免叠加一组互相冲突的近似规则。
- 保留键盘焦点、图标按钮的可访问名称和主要操作约 44px 的点击目标。视觉尺寸与点击区域可以不同。
- 为不支持 backdrop-filter 的环境提供实色背景；降低透明度偏好下使用不透明中性色；减少动态效果偏好下关闭或简化装饰动画。
- 按需检查窄屏、长昵称、多标签、多行更新记录、空列表、加载和失败状态，以及导航遮挡、横向溢出和头像尺寸。
- 将构建、资源上线、浏览器视觉检查和真实设备传感器检查分别报告。源代码或构建通过不代表设备体验已验证。
- 验证范围服从用户当前要求；若用户已免除 design-qa，不因该流程额外暂停或索取批准，仍准确说明实际做过的检查。
