# 页面规则与起始参数

依据 2026-10-14 的 online-excel 样式及本次会话反馈整理。以下数值是可复用起点，不是官方 iOS 尺寸规范，也不表示已完成真机视觉验收。

## 基础参数

| 项目 | 起始值 |
| --- | --- |
| 常驻顶部 | 48px；主标题 19px / 窄屏 18px；详情标题 17px |
| 顶部统计 | 标签 12px，数字 15px；单行无背景 |
| 正文宽度 | `min(720px, 100%)`；左右 20px，窄屏 16px |
| 页面底部留白 | 约 `124px + env(safe-area-inset-bottom, 0px)`，随导航实际高度调整 |
| 正文 / 次要文字 / 强调色 | `#1c1c1e` / `#8e8e93` / `#007aff` |
| 内容底 / 分组页面底 | `#fff` / `#f2f2f7` |
| 分隔线 | `1px solid rgba(60, 60, 67, .13)` |
| 列表姓名 / 正文 | 16–17px，姓名约 600 字重，正文 1.6–1.75 行高 |
| 组标题 / 辅助说明 | 22–23px / 12–13px |
| 内容组 / 组间距 | 约 24px 圆角；16px 间距；20–22px 内边距 |
| 搜索 | 42px 高，12px 圆角，16px 输入字号，浅灰底 |
| 标签 | 6px 圆角；约 11px 字号；少量语义色，无阴影 |

不要把窄屏现有的 10–11px 统计字固定为所有项目的正文标准；内容拥挤时优先重排并检查可读性。

## 精选入口

蓝色底参考 `#76a8db`，约 28px 圆角，26px 内边距；使用真实头像拼贴。标题约 32px，窄屏约 28px；引导和成员说明约 12–13px。“打开”使用浅色小胶囊与箭头。允许轻微阴影帮助这张精选卡片呈现独立层次，普通列表和统计控件保持平面。

## 玻璃 Tabbar 的最低完整实现

优先使用 `$super-ios-glass-tabbar` 中的完整指导；不可用时参考：

| 部分 | 值 |
| --- | --- |
| 容器 | `min(480px, calc(100% - 32px))`；68px 高；5px 内边距；999px 圆角 |
| 材质 | `rgba(250, 250, 252, .24)`；`blur(12px) saturate(150%)` |
| 细边 / 阴影 | `1px solid rgba(255,255,255,.9)`；`0 2px 12px rgba(0,0,0,.06), inset 0 1px 0 rgba(255,255,255,.65)` |
| 选中层 | `rgba(224,224,228,.3)`；高度 `calc(100% - 6px)`；无独立模糊、边框或阴影 |
| 文字与图标 | 常态 `#1c1c1e`；选中 `#007aff`；图标 25px；标签 11px、600 字重；间距 3px |
| 动画 | 位置与宽度 330ms，`cubic-bezier(.22,.78,.24,1)` |
| 底部距离 | `max(12px, calc(env(safe-area-inset-bottom, 0px) + 10px))` |

选中胶囊置于内容后方，`pointer-events: none`；根据真实 tab 宽度减去 4px 计算尺寸，并限制在容器范围内。首次测量后再启用过渡，路由及容器尺寸变化时重算。图标使用稳定字形与继承颜色，清除 filter、text-shadow 和背景等异常效果。

## 代码定位（仅在原项目使用）

- `web/src/liquid-glass.css`：当前页面主题，晚于历史样式加载。
- `web/src/App.vue`：页面结构、导航、顶部统计和开屏模式。
- `web/src/AvatarPhysics.vue`：物理舞台与重力状态 UI。
- `web/src/device-gravity.js`：方向/重力数据和授权状态。

移植到其他项目时按页面角色映射组件，不要求这些路径、框架或业务名称存在。
