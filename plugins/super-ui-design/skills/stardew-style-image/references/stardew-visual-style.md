# 星露谷物语像素农场游戏截图视觉风格

本文档是 `stardew-style-image` 的内置视觉规范。写提示词前先按本文档确定画风、季节、场景、生活动作、像素 UI、中文文字和元素池。

## 1. 画面总目标

默认按"星露谷物语风格像素农场生活模拟游戏截图"方向写 prompt，不是普通可爱插画、不是 3D 农场、不是写实摄影、不是手游经营界面、不是旅游海报。

**画风字段标准写法**：

```text
星露谷物语风格像素农场生活模拟游戏截图
画风：Stardew Valley 风格 2D 像素艺术游戏截图；俯视轻等距视角；清晰像素块、温暖田园色彩、低分辨率游戏画面感；不要 3D 渲染、不要写实摄影、不要高清插画、不要电影 CG、不要矢量扁平图标
```

- 画风字段只保留"2D 像素艺术游戏截图 + 俯视轻等距 + 反向声明禁词"。不要在其他字段重复写像素、复古、低清、卡通、可爱等风格词。
- 不要写摄影镜头、焦段、景深、电影光效、真实材质、HDR、超清细节、体积光、真实阴影。
- 不要写成 App UI、经营看板、信息图、广告海报、封面 Logo、社交媒体贴图。
- 默认是正在游玩的游戏截图：场景中有角色、生活动作、可交互物体和少量 HUD。

## 2. 视角与构图规则

- 默认使用俯视轻等距视角，像农场生活模拟游戏画面。
- 农场、小镇、室内、温室、矿洞、海边都保持可游玩视角，角色和物体按格子化空间自然摆放。
- 不要写第一人称、电影特写、大景深摄影、角色半身海报。
- 如果用户明确要求物品图标、头像、菜单界面或封面，才脱离默认游戏截图视角。
- 主体要可识别，但不要让单个物体占满画面。产品或地标应融入农场/小镇场景，而不是被做成广告展示图。

## 3. 季节与时间规则

`季节与时间` 是必填字段。星露谷风格的识别度很大程度来自季节色彩和生活节奏。

用户提供真实拍摄时间时，优先保留为可读 UI 或事件语义；未提供时按画面氛围选择默认季节与时间，不要编造具体日期。

真实时间转译规则：

- 节日/假期：可写进日期 UI、任务标题、节日摊位或拍照点，例如 `2026 春节`、`2026 五一假期`。
- 具体日期：可转成像素 UI 日期，例如 `2026 年 5 月 1 日` 可写作 `2026 五一假期` 或 `春季/夏季节日第 1 日`，保持中文可读。
- 模糊时间：如 `春节`、`五一`、`暑假`，按用户原词保留，不自行补全日期。
- 未提供真实时间：只写 `春/夏/秋/冬 + 清晨/正午/黄昏/夜晚`。

### 春天

- 新绿草地、翻耕土、幼苗、野花、樱花或浅色花树、清晨露水感。
- 适合播种、浇水、初建农场、小镇集市、送礼、春季节日。

### 夏天

- 浓绿植被、成熟作物、海边、钓鱼、蜂箱、明亮日照、夜市氛围。
- 适合钓鱼、收获、浇水、赶集、海边码头、户外摊位。

### 秋天

- 橙黄树叶、南瓜、玉米、葡萄、稻草人、丰收感、黄昏色调。
- 适合收获、农产品集市、咖啡馆、木屋室内、节日摊位。

### 冬天

- 雪地、光秃树枝、温室、室内壁炉、矿洞、节日灯串、安静小镇。
- 适合采矿、室内烹饪、温室种植、冬季市集、礼物交换。

时间可选：清晨、正午、黄昏、夜晚。不要写复杂光线，只写时间词。

## 4. 场景类型

按用户主题选择一种主场景，不要把所有场景塞进同一张图。

- 农场：作物田、木栅栏、洒水器、稻草人、收货箱、鸡舍、畜棚、池塘。
- 小镇广场：石路、公告栏、商店、喷泉、长椅、摊位、像素 NPC。
- 海边码头：木栈桥、鱼竿、水桶、贝壳、小船、海边商店。
- 矿洞：岩壁、矿石、木梯、轨道、火把、史莱姆、宝箱。
- 温室：玻璃房、整齐作物、果树、洒水器、木桶、盆栽。
- 木屋室内：木地板、壁炉、厨房、床、工作台、箱子、地毯、家具。
- 森林与山路：野莓、蘑菇、树桩、木桥、湖边、采集点。
- 节日广场：摊位、彩旗、长桌、NPC 聚会、比赛台、礼物桌。

## 5. 生活动作规则

`生活时刻` 必须写一个具体、可玩的动作。不要写抽象情绪或宣传语。

可用动作：

```text
浇水、播种、收获、锄地、砍树、采集、钓鱼、挖矿、打怪、烹饪、酿造、送礼、交谈、购买、出售、赶集、布置农场、喂动物、拾取、打开宝箱
```

动作写法保持一句话，例如：

```text
生活时刻：玩家角色正在给南瓜田浇水，旁边 NPC 在摊位前交谈
```

不要写身体微观细节、表情特写、手指动作、复杂运镜。

## 6. 像素 UI 规则

UI 是农场模拟游戏截图里自然出现的界面状态，不是信息图。

可自然出现 1-4 种：

- 日期
- 星期
- 时间
- 金币
- 体力条
- 工具栏
- 物品栏
- 对话框
- 商店菜单
- 任务提示
- 物品拾取提示

不要在 prompt 里写死 UI 的位置、尺寸、按钮形状、像素数量、排列方式或精确数值。写一句方向性说明即可：

```text
像素 UI：按农场模拟游戏截图自然出现，可有日期、时间、金币、体力条、工具栏或物品栏，不堆满
```

如果用户明确要商店、对话或节日活动，可以写可读中文内容，但不要加现代 App 风弹窗、二维码、badge、导航栏。

真实时间/地点进入 UI 时，优先选择自然承载位：

- 时间：日期角标、节日标题、任务提示、拍照提示。
- 地点：木牌、店铺招牌、地图标记、拍照点牌、任务提示、NPC 对话。
- 店铺名：真实地点 + 功能名，例如 `仙台的杂货店`、`宜兴茶叶铺`、`五台山森林驿站`。
- 拍照点：真实地点 + 纪念语义，例如 `青海小柴旦湖`、`五台山森林入口`。

不要把真实地点做成大幅旅游标题或海报标语。地点文字应像游戏内木牌、店名、地图标记或小型任务 UI。

## 7. UI 文字中文化规则

画面里的可读文字要像中文本地化游戏 UI。

必须使用中文的位置：

- 动作提示
- 对话框
- 商店菜单
- 物品名
- 任务提示
- 地图标记
- 店铺招牌
- 节日牌子

中文动词清单：

```text
浇水、收获、钓鱼、交谈、购买、出售、赠送、拾取、打开、烹饪、制作、采集、挖矿、装备、放置
```

严禁出现英文 UI 词：Water、Harvest、Fish、Talk、Buy、Sell、Gift、Pick up、Open、Cook、Craft、Mine、Equip。

文字无法清晰时，优先减少文字，只保留短中文词。不要乱码、伪英文、外挂字幕或广告标语。

## 8. 原版感元素池

按场景气质挑选组合，不要清单式摆拍。

### 角色与 NPC

玩家角色、农夫、店主、渔夫、矿工、木匠、医生、酒馆老板、旅行商人、小镇居民、节日游客。

### 作物与植物

防风草、草莓、蓝莓、甜瓜、南瓜、玉米、葡萄、咖啡豆、啤酒花、果树、野花、蘑菇、野莓、盆栽。

### 建筑与设施

木屋、鸡舍、畜棚、温室、筒仓、鱼塘、风车、商店、酒馆、诊所、木匠铺、矿洞入口、海边小屋。

### 工具与互动物

水壶、锄头、斧头、镐子、鱼竿、镰刀、洒水器、稻草人、收货箱、木箱、宝箱、木桶、蜂箱、熔炉、工作台。

### 动物与生物

鸡、鸭、牛、羊、猪、猫、狗、马、鱼、蝴蝶、史莱姆、蝙蝠。

### 小镇生活元素

公告栏、石路、木栅栏、路灯、长椅、摊位、彩旗、礼物盒、咖啡杯、餐桌、货架、厨房、壁炉。

## 9. 真实地点与产品转译

真实地点、品牌产品或人物主题要转译成星露谷世界中的可玩场景。

- 真实地点：保留 3-6 个核心识别特征，转译为小镇街区、农场边缘、节日广场、海边码头、森林山路或室内店铺。
- 用户提供真实地点时，必须优先用于可读中文 UI 或场景物件，不要被通用地点替代。例：`日本仙台` 可转为 `仙台的杂货店`；`宜兴` 可转为 `宜兴茶园` 或 `宜兴茶叶铺`；`青海小柴旦湖` 可转为湖畔木牌/拍照点；`五台山` 可转为 `五台山森林入口`。
- 用户没有提供真实地点时，使用通用场景名，例如 `森林入口`、`海边码头`、`小镇广场`，不要猜测城市或景区。
- 产品物体：保留外形、颜色、用途或关键部件，放进商店货架、节日摊位、木屋工作台、农场箱子或 NPC 手中。
- 真实人物：转译为像素 NPC 或玩家角色，保留职业/服饰/动作的简短识别点，不写真实肖像摄影。
- 现代设施：转译为木牌、摊位、工具台、货架、公告栏、农场机器或小镇建筑，不要写出现代 App 屏幕、玻璃写字楼、二维码广告牌。

## 10. 组图人物一致性与差异化

多张照片属于同一人物、情侣、家庭或团队时，先抽取一条全组人物设定，再在每张 prompt 复用。

人物一致性优先保留：

- 身高关系、体型比例、发型长度、发色、是否戴眼镜或墨镜。
- 情侣/朋友/家庭关系，以及牵手、并肩、拥抱、背影或合照等关系姿态。
- 每张照片中最有辨识度的服装或配饰；季节转译时可适度像素化，但不要完全换人。

组图差异化要求：

- 每张使用不同的主场景、生活动作或 UI 承载方式。
- 不要每张都显示底部工具栏；可交替使用日期角标、木牌、商店菜单、对话框、拍照提示、拾取提示或无 HUD 场景。
- 同一地点类型连续出现时，用真实地点、时间、道具和生活动作区分。
- 组图中可有 1-2 张完整 HUD，其余优先轻 UI 或场景内木牌。

## 11. 必须避免清单

- 不要 3D 渲染、写实摄影、高清插画、电影 CG、矢量扁平图标。
- 不要现代手游经营界面、满屏按钮、任务面板、抽卡弹窗、排行榜。
- 不要旅游海报、品牌广告图、Logo 标题页、水印、二维码。
- 不要把 UI 堆满画面；要像一张正在游玩的农场生活模拟游戏截图。
- 不要长篇材质、光线、镜头、构图分层描述。
- 不要把所有元素排成清单式摆拍；元素要和生活动作产生关系。
- 不要英文 UI、乱码、伪文字、外挂字幕。
