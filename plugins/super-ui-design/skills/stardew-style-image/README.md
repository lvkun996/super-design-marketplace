# stardew-style-image

This Codex Skill turns uploaded photos into Stardew Valley-style pixel images. It preserves the original people, relationships, composition, and key scene details, then reimagines them as warm pixel-art farm, town, forest, seaside, or festival scenes. If the user provides a real location and date, the Skill can naturally weave them into in-game signs, shop names, date UI, quest prompts, or photo spots, making each image feel like a personalized memory inside a cozy farming sim.
