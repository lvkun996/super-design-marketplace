# 星露谷物语风格图片

用这个技能写稳定、简洁、可直接交给生图模型的星露谷物语风格图片提示词。

## 自带依赖

写提示词前先读 `references/stardew-visual-style.md`，拿完整视觉规范、季节规则、像素 UI 规则、场景类型和元素池。

这个技能是独立提示词技能，随 skill 一起发布的 `references/` 已包含所需视觉规范。

## 提示词模板

默认使用这个模板。替换方括号里的内容，并保持行序。

```text
星露谷物语风格像素农场生活模拟游戏截图
画风：Stardew Valley 风格 2D 像素艺术游戏截图；俯视轻等距视角；清晰像素块、温暖田园色彩、低分辨率游戏画面感；不要 3D 渲染、不要写实摄影、不要高清插画、不要电影 CG、不要矢量扁平图标

季节与时间：[春/夏/秋/冬]，[清晨/正午/黄昏/夜晚]
真实时间/地点（可选）：[用户提供时填写，例如「2026 春节，宜兴」/「2026 五一假期，青海小柴旦湖」；未提供则省略本行]
场景地点：[农场/小镇广场/海边码头/矿洞/温室/木屋室内/真实地点转译主题]
画面要素：[3-6 个可识别关键词，只列名词或短词组]
生活时刻：[一句话叙事，写角色正在做什么，例如浇水、收获、钓鱼、挖矿、送礼、赶集、布置农场]

星露谷元素：[4-8 个关键词，只列名称不展开外观]
像素 UI：按农场模拟游戏截图自然出现，可有日期、时间、金币、体力条、工具栏或物品栏，不堆满
文字：所有可读 UI 使用中文，动词只用中文，如「浇水」「收获」「钓鱼」「交谈」「购买」「赠送」
```

## 填写规则

- 提示词控制在 8-11 行左右。不要写成长篇分镜，不要堆材质、光影、镜头焦段。
- `画风` 行集中写像素游戏截图风格和反向禁词；其他字段不要重复写像素、复古、低清、可爱等风格词。
- 默认使用俯视轻等距视角。只有用户明确要求头像、物品图标、菜单界面、横版场景或封面图时，才改变视角。
- `季节与时间` 必须明确。星露谷风格高度依赖季节色彩、作物状态和时间氛围。
- 用户提供真实拍摄时间或地点时，优先写入 `真实时间/地点（可选）`；未提供时省略该行，不要自行编造具体日期或城市。
- 真实时间可转译进像素 UI 的日期、节日、任务标题或拍照点标注，例如 `2026 春节`、`2026 五一假期`。真实地点可转译进店名、木牌、地图标记、拍照点或任务提示，例如 `仙台的杂货店`、`宜兴茶园`、`青海小柴旦湖`、`五台山森林入口`。
- `场景地点` 是风格锚点字段。真实地点可以转译为农场、小镇街区、集市、温室、矿洞、海边码头或节日广场，但不要做成旅游海报。
- `画面要素` 承担主体辨识度，使用地标、物体、角色、作物、建筑或产品特征等短关键词。
- `生活时刻` 必须是可玩的农场生活动作，不要写抽象情绪、品牌口号或广告文案。
- `星露谷元素` 只写紧凑列表，例如 `木栅栏、洒水器、稻草人、鸡舍、作物田、收货箱、像素 NPC、节日摊位`。不要展开形状、颜色、材质或位置。
- 如果用户要求真实人物或品牌产品，保留核心识别特征，但转译为像素小镇/农场世界中的可玩对象，不要写实现代摄影。
- 组图任务中，如果多张照片属于同一人物、情侣、家庭或团队，必须在每张 prompt 中加入简短一致性约束，保持身高关系、发型、主要服装特征和人物关系；同时让场景元素、UI 类型和互动动作有差异，不要每张都使用同一套工具栏或同一类提示。
- HUD/UI 只写自然出现，不要指定屏幕角落、像素数量、按钮形状、精确布局。
- 除非用户明确要求封面、海报或图标，否则不要生成标题页、Logo、水印或宣传图。

## 输出模式

只返回最终提示词代码块，不要附带任何其他说明。
